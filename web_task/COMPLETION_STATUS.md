## 🚀 How to Start Using It

### Step 1: Start the Backend (2 minutes)
```bash
cd server
npm start
```
✅ Server runs on `http://localhost:5000`

### Step 2: Access Admin Dashboard
```
http://localhost:5000/admin
```
✅ You'll see the login page

### Step 3: Create Admin Account (1 minute)
```
1. Click "Register here"
2. Enter email: admin@example.com
3. Enter password: Test123!
4. Click Register
5. You're logged in!
```

### Step 4: Start Using Features
- **Add Hotels**: Click "➕ Add New Hotel" and fill the form
- **Edit Hotels**: Click "✏️ Edit" on any hotel
- **Delete Hotels**: Click "🗑️ Delete" to remove hotels
- **Manage Bookings**: Switch to "Bookings" tab
- **Confirm Bookings**: Click "✓ Confirm" on any booking
- **Reject Bookings**: Click "✕ Reject" on any booking
